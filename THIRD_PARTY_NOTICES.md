The twelve traineddata files are redistributed unmodified; their SHA256 pins
are in the README's artifact table ("Vendored language data") and, for the six
added last, in the table below, and `tests/test_vendored_assets.py` checks the
bytes against both. `eng`, `msa` and `lao` were vendored earlier and are pinned
by digest alone; `ind`, `tha` and `rus` were taken from tag 4.1.0 and each was
checked against that tag's GitHub blob SHA on download (16 Sep 2026); `chi_sim`,
`vie`, `kaz`, `mon` and `hin` were taken from the same tag and checked the same
way (29 Sep 2026), and `por` (Portuguese, for Timor-Leste) likewise (30 Sep 2026). `vendor/wordlist_legal_en.txt` is not third
party: it is generated by this project from its own extraction streams
(`scripts/make_wordlist.py`).

Notices for the shipped audit UI bundle live in
`src/regcompass/ui_dist/THIRD_PARTY_NOTICES.md`, which ships inside the wheel
next to the bundle it describes: React, the fonts (IBM Plex, Newsreader and
Noto Sans Lao), and PDF.js including its WebAssembly image decoders. Those decoders are redistributed unmodified at
`src/regcompass/ui_dist/wasm/`, with each one's own upstream licence text in
the same folder, because a scanned law cannot be displayed without them and
fetching them from a CDN is not an option offline.
