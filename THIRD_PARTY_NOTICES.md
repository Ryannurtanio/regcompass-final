# Third-party notices (vendored assets)

Third-party components vendored directly in this repository, outside the
Python dependency set (which is covered by the pip-licenses gate in CI).

| Component | Location | License | Source |
|---|---|---|---|
| Tesseract OCR language data, `eng` + `msa` + `lao` (tessdata_best) | `vendor/tessdata/` | Apache-2.0 | https://github.com/tesseract-ocr/tessdata_best |
| Tesseract OCR language data, `ind` + `tha` + `rus` (tessdata_best, tag 4.1.0) | `vendor/tessdata/` | Apache-2.0 | https://github.com/tesseract-ocr/tessdata_best |
| UN Global Hackathon final-round output template, unmodified | `config/organizer/OUTPUT_TEMPLATE_FINAL_ROUND.xlsx` | none stated: the hackathon secretariat's own submission template, supplied to finalists to fill in | the 18 August 2026 finalist orientation materials |
| opus-mt-mul-en translation model (Helsinki-NLP), fetched and converted to CTranslate2 int8, never committed | `models/opus_mt_mul_en_ct2/` via `scripts/fetch_m3_weights.py` (gitignored) | Apache-2.0 (the Hugging Face distribution's license tag, set by the model authors; the CT2 conversion is a derivative of those weights) | https://huggingface.co/Helsinki-NLP/opus-mt-mul-en |

The six traineddata files are redistributed unmodified; their SHA256 pins are
in the README's artifact table ("Vendored language data"), and
`tests/test_vendored_assets.py` checks the bytes against it. `eng`, `msa` and
`lao` were vendored earlier and are pinned by digest alone; `ind`, `tha` and
`rus` were taken from tag 4.1.0 and each was checked against that tag's GitHub
blob SHA on download (16 Sep 2026). `vendor/wordlist_legal_en.txt` is not third
party: it is generated by this project from its own extraction streams
(`scripts/make_wordlist.py`).

Notices for the shipped audit UI bundle live in
`src/regcompass/ui_dist/THIRD_PARTY_NOTICES.md`, which ships inside the wheel
next to the bundle it describes: React, the fonts (IBM Plex, Newsreader and
Noto Sans Lao), and PDF.js including its WebAssembly image decoders. Those decoders are redistributed unmodified at
`src/regcompass/ui_dist/wasm/`, with each one's own upstream licence text in
the same folder, because a scanned law cannot be displayed without them and
fetching them from a CDN is not an option offline.
